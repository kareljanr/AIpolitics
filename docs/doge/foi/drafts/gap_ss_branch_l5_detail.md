   (Algemene Toelichting DOC 56 1278/001 Tabel I.2:
   **€63.342 miljoen**) naar minstens: pensioenen, werkloosheid,
   ziekte/invaliditeit, arbeidsongevallen/beroepsziekten, gezinsbijslagen
   (indien nog federaal), overige.

   met de RIZIV-globale begroting / zorgkrediet (historisch ~€45 miljard-klasse).

3. **Beheerskosten diensten derden** **€1.754 miljoen** 2026: uitsplitsing
   per betaalorganisme / mutualiteit / kanaal.

Periode: 2025 (geactualiseerd) en 2026 (initieel).

### 2. Context
