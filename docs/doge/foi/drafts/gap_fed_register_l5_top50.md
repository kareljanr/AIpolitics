# FOI draft — gap_fed_register_l5_top50

**Status:** ready (human send only)  
**Topic:** Machine-readable top-50 named federal toelage beneficiaries

## Known (public, strong)

- BOSA Federaal register financiële overdrachten: **€179.916 bn / 8.993 items (2025)**  
- Aggregates by type (households €141.9 bn, regions €19.4 bn, firms €4.8 bn, local €4.7 bn, foreign €2.6 bn, Maribel €0.89 bn, BV TE €4.7 bn)  
- Departmental / OISZ / AOI subtotals published  
- Interactive UI has beneficiary name + KBO + amount; **no bulk CSV** found 2026-07-27

## Missing
